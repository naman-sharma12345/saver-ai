1. Project Overview

SaverAI is an AI-powered student expense management platform that helps students track spending, discover savings opportunities, and build healthier financial habits through machine learning-driven insights.

The system combines 7 distinct ML/statistical techniques across 6 modules to deliver intelligent expense categorisation, anomaly detection, spending prediction, budget optimisation, recurring pattern detection, and savings goal simulation.

4. Machine Learning Pipeline

SaverAI employs 7 distinct ML/statistical techniques across 6 modules. Each is described below with its algorithm, feature engineering, and evaluation methodology.

4.1 Expense Category Classifier

Module: ml/categorizer.py

Algorithm: LinearSVC (Support Vector Classifier)

Features: TF-IDF vectors from descriptions

Training: GridSearchCV, 5-fold CV

Classes: 8 expense categories

Accuracy: 99.42%

Feature Engineering Pipeline

Raw Text → Lowercase → TF-IDF Vectorisation (max_features=5000, ngram_range=(1,2), sublinear_tf=True)

Model Pipeline

Pipeline([
    ('tfidf', TfidfVectorizer()),
    ('clf', OneVsRestClassifier(LinearSVC()))
])

4.2 Anomaly Detection (Unusual Spending)

Module: ml/anomaly_detection.py

Algorithm: Isolation Forest

Features: Amount, Day-of-Month, Hour-of-Day

Contamination: 10% · Trees: 100

How It Works

  1. Feature extraction: Each expense → [amount, day_of_month, hour_of_day]
  2. Normalisation: Z-score: (X - μ) / σ
  3. Isolation Forest recursively partitions feature space; anomalies need fewer splits to isolate
  4. Scoring: decision_function() returns anomaly scores; lower = more anomalous
  5. Explanation: Auto-generates natural language explanations

Why Isolation Forest?

  • Works well with high-dimensional data and small sample sizes
  • Doesn't assume any distribution shape (unlike Z-score thresholding)
  • Linear time complexity O(n log n) — fast for real-time detection
  • Handles both unusually high AND low spending

4.3 Spending Predictor (Next Month Forecast)

Module: ml/spending_predictor.py

Algorithm: Linear Regression

Features: Monthly index (time series)

Confidence: 95% CI using residual std error

Model

y = β₀ + β₁ · month_index + ε
Where:
  y = predicted total spending for next month
  month_index = sequential integer (0, 1, 2, ... n)
  ε ~ N(0, σ²)
